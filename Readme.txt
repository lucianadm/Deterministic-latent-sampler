# Deterministic Latent Space Sampler

Deterministic sampling of autoencoder latent spaces using
data-driven piecewise-linear expanding maps.

This repository accompanies the paper:

Deterministic Sampling of Autoencoder Latent Spaces via Data-Driven
Piecewise-Linear Expanding Maps

## Overview

This code implements a fully deterministic generative mechanism operating
directly in learned latent spaces. The method constructs context-dependent
piecewise-linear expanding maps from empirical conditional distributions.

For each latent coordinate and conditioning context, an inverse
Frobenius–Perron construction is used to synthesize a one-dimensional map
whose prescribed invariant probability density locally approximates the
corresponding empirical conditional distribution.

The resulting latent sampler uses a state-dependent deterministic switching
rule to select and iterate these local maps.

Unlike diffusion- or flow-based approaches, the sampler:

* does not require stochastic noise,
* does not learn an additional vector field or sampling network,
* does not assume a Gaussian prior.

New latent samples are generated through deterministic iteration.

The expansion properties verified in the accompanying work apply to the
constituent one-dimensional maps. No claim is made that the complete
high-dimensional state-dependent switching system possesses a global
invariant measure or global chaotic dynamics.

## Method summary

1. Each latent dimension is discretized into `B` coarse bins.
2. Conditional fine histograms are estimated for the occupied context cells
   defined by the remaining latent dimensions.
3. Piecewise-linear expanding maps are synthesized through an inverse
   Frobenius–Perron construction.
4. At each iteration, the current latent state determines the appropriate
   context-dependent map for each coordinate.
5. New latent samples are generated by deterministic iteration.

The method can be used in:

* single-seed mode, which generates a trajectory from a single initial
  latent vector,
* multi-seed mode, which evolves an ensemble of initial latent vectors
  for distribution-oriented sampling.
